
# data_ingestion_pipeline_RAGModel

## 📘 Overview
This project implements a Retrieval-Augmented Generation (RAG) pipeline that automates document ingestion, text extraction, chunking, embedding, and semantic search using Milvus and local LLMs. It’s designed to be modular, reproducible, and easy to integrate with tools like n8n and Ollama.
